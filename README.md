# Sales & Customer Analytics using SQL

## Overview
An end-to-end SQL analytics project using a sales data warehouse to explore customer behavior, product performance, and sales trends. The project applies SQL Server queries to transform raw data into customer and product reports that support data-driven business decisions.

## Objectives
- Analyze sales performance and revenue trends.
- Identify top-performing products and customer segments.
- Evaluate customer purchasing behavior and product contribution.
- Create reusable analytical reports using SQL views.

## Tools & Skills
**SQL Server · T-SQL · SSMS · Joins · CTEs · Window Functions · Subqueries · Aggregations · CASE Statements · Date Functions · Views**

## Analysis Performed
- **Exploratory analysis:** Inspected database tables, dimensions, date ranges, and key measures.
- **Sales analysis:** Examined revenue, quantity sold, order activity, and customer contribution.
- **Ranking analysis:** Ranked products and customers by relevant sales metrics.
- **Time-based analysis:** Analyzed sales patterns and changes over time.
- **Cumulative analysis:** Calculated running totals and cumulative performance.
- **Segmentation:** Grouped customers and products into analytical categories.
- **Reporting:** Created customer and product reports with metrics such as total sales, orders, quantity, customer lifespan, recency, and average order value.
